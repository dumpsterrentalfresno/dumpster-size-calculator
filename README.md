# Dumpster Size Calculator

Free Firefox extension that helps you pick the right dumpster size (10/20/30/40 yard) for your cleanout, renovation, roofing, or construction project.

Answer a few simple questions about your project, debris type, and estimated volume, and the extension recommends the best-fitting dumpster size so you avoid overpaying for space you do not need or running out of room halfway through the job.

## Features

- Size recommendations for 10, 20, 30, and 40 yard dumpsters
- Guidance for cleanouts, renovations, roofing, construction, yard waste, and demolition projects
- Estimates based on project type, debris type, and volume
- Simple, fast, and free to use in Firefox
- No account or sign-up required
- Clear explanations of what fits in each dumpster size

## Installation

1. Download or clone this repository.
2. Open Firefox and go to `about:debugging#/runtime/this-firefox`.
3. Click **Load Temporary Add-on**.
4. Select the extension manifest file from this repository.
5. Open the extension from the Firefox toolbar and follow the on-screen steps to calculate your dumpster size.

For a published release, download the latest `.xpi` file from the Releases page, then drag and drop it into Firefox and confirm installation when prompted.

## How to Choose the Right Size

- **10 yard:** Small cleanouts, garage cleanups, and small bathroom remodels.
- **20 yard:** Medium cleanouts, flooring removal, roofing jobs, and kitchen remodels.
- **30 yard:** Large cleanouts, major renovations, and construction debris.
- **40 yard:** Large construction projects, commercial cleanouts, and whole-home renovations.

When in doubt, check this [roll-off dumpster guide](https://dumpsterrentalsfresno.com/) before you book, and [learn more about dumpster sizes](https://dumpsterrentalsfresno.com/) to compare capacity, dimensions, and typical projects for each size.
